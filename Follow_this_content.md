```
Add a flow diagram or a use case diagram or an architecture diagram.

CLOSED-LOOP CYCLE (End-to-End Workflow):

STEP 1: CITIZEN INPUT (Offline/Online)
→ Citizen captures photo of sanitation issue
→ Optional voice note for context (60 seconds, 7 languages)
→ App stores locally if offline
→ Auto-uploads when connectivity available
→ Unique ticket ID generated instantly (e.g., SAN123456)

STEP 2: AI TRIAGE (< 5 seconds)
→ Photo sent to Amazon Bedrock (Claude 3 Sonnet Vision):
   - Classifies issue type: garbage pile, drain, sewer, etc.
   - Scores severity (1-10 scale based on visual cues)
   - Detects spam (95%+ accuracy)
   - Generates human-readable description
→ Amazon Rekognition provides supplementary object labels
→ Amazon Transcribe processes voice note (7 Indian languages)
→ Transcribed text → Bedrock: extracts urgency keywords
→ Final severity score calculated (image + voice context)

STEP 3: LOGISTICS OPTIMIZATION (Daily)
→ Amazon Bedrock generates optimized task sequences
→ Considers all pending high-priority issues
→ Factors: urgency, geographic clustering, severity
→ Assigns prioritized tasks to sanitation workers

STEP 4: FIELD ACTION (Real-time)
→ Worker receives task on mobile app (Uber-like interface)
→ Turn-by-turn navigation to exact location
→ Views "Before" photos and issue details
→ Completes cleanup
→ Uploads "After" photo (mandatory for task completion)

STEP 5: AI VALIDATION (< 10 seconds)
→ Retrieves "Before" photo from S3
→ Both images sent to Amazon Bedrock (Claude 3 Sonnet Vision):
   - Compares before vs after images
   - Calculates waste reduction percentage
   - Detects staged or fake photos
→ GPS proximity check (within 20 meters)
→ If ≥70% reduction → Approve → Close ticket
→ If <70% reduction → Reject → Keep ticket open → Notify worker

STEP 6: OUTCOME & ANALYTICS
→ Ticket status updated on dashboard
→ Authorities notified of completion
→ Hotspot detection algorithm runs (5+ reports in 30 days)
→ Epidemic risk scores updated daily
→ Performance metrics calculated
→ Citizen receives SMS confirmation

CONTINUOUS MONITORING (RAG-Powered):
→ Amazon Bedrock Knowledge Base (RAG) generates epidemic risk advisories
→ RAG sources: WHO sanitation guidelines, disease correlation data
→ Amazon Titan Embeddings index health documents in vector store
→ Daily epidemic risk assessment per geographic zone
→ Weekly reports to health officials
→ Monthly performance reviews
→ Quarterly strategic planning
```
